Check and fix the notes (optional)

Blue circles mark what was read. Fix any wrong note below (type a name like C4, F#3, Bb4, or R for a rest; a chord is several names, like C5 A4), change its length, delete it, or add a rest with ＋. Then tap Update.

Works best with clean, computer-made PDFs. It follows the melody (the top note of stacked chords) and reads note lengths, rests, ties, dotted notes, triplets and sharps/flats. It plays straight through, so repeats and endings are not followed. Check the notes if something sounds off.
